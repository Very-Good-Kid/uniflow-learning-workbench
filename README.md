# 高校智能学习工作台 · 界面层静态交互原型

为「高校智能学习工作台」（Vue 3 + Cordis + MySQL，见开发交接文档）配套做的界面层静态交互原型。不含真实后端，数据全部来自本地 mock，用来在写代码之前把页面结构、交互流程和状态细节定下来，开发照着实现即可。

本仓库是对外发布的静态快照。纯静态、零构建、不依赖任何 CDN。

## 在线访问

- GitHub Pages：<https://very-good-kid.github.io/uniflow-learning-workbench/>（入口为交付清单页 index.html）
- 备用链接（WorkBuddy 托管，临时）：<https://uniflow-prototype.app.workbuddy.host/?sharecode=CNASW56UXD>

## 怎么跑

两种方式任选：

1. 直接双击任意 `*.html`，浏览器本地打开；
2. 或者起个本地服务，体验和线上一致：

```bash
python -m http.server 8080
# 访问 http://localhost:8080
```

## 页面清单

10 个页面，入口是 `index.html` 的交付清单。

| 文件 | 页面 | 说明 |
|---|---|---|
| `index.html` | 交付清单 | 全部页面入口，标注批次与对应交接文档章节 |
| `home.html` | 学习工作台（首页） | 概览四格 / 今日安排 / 待办快速完成 / AI 规划入口 |
| `tasks.html` | 课程与任务 | 两行筛选、批量操作、任务表格、详情·编辑·新建抽屉，支持 `?id=`、`?new=1` 深链接 |
| `schedule.html` | 日程 | 七列周视图，真实钟点 7:00–23:00，冲突检测，点空白格新建，支持 `?date=` / `?event=` / `?course=` |
| `ai-plan.html` | AI 学习规划 | 左对话 + 右候选计划，文本为唯一入口，意图识别画成「已理解」条，确认后写回日程 |
| `library.html` | 学习资料库 | 列表 / 卡片流双视图，课程筛选卡带，详情抽屉，支持 `?q=` |
| `messages.html` | 消息与通知 | 顶栏铃铛对应的完整页面，含系统公告；标为已读后自动跳到下一条未读，未读清完时两栏一起收空 |
| `profile.html` | 个人中心 | 学籍卡（身份信息只读）；学习偏好、通知与提醒各为一个二级抽屉；另有头像昵称、登录方式、登录记录 |
| `login.html` | 登录 | 校园照片打底、登录卡居中，账号密码 / 扫码双页签，演示身份弹窗可切管理员、学生、停用账号 |
| `admin.html` | 系统管理 | 管理员后台，六个分支：用户管理、课程目录、资料管理、公告发布、系统配置、同步状态（只读） |

全站共用侧边栏 6 项导航 + 底部「系统管理」、顶部搜索框与铃铛。「消息与通知」不占一级菜单，走顶栏铃铛。顶栏用户区点击直接进个人中心，没有下拉菜单。

顶栏还有一套全局搜索（Ctrl+K）：搜的是对象不是页面，按任务 → 资料 → 日程 → 课程 → 消息五类优先级命中，课程支持「高数 / 计网」等简称，↑↓ 选择、回车直达对应页面详情。列表页的过滤与搜索面板共用同一套匹配口径，避免面板条数和落地条数对不上。

## 设计与实现约定

配色是学术绿体系，主色 `#006D5B`。全部令牌只在 `app.css` 的 `:root` 定义一次（`--brand-*` / `--warm*` / `--indigo*` / `--alert*`），并已接线 TDesign 主题变量。品牌名、学校名、导航、学期、演示账号只改 `config.js` 一处，禁止逐页替换。界面里显示的品牌是「高校智能学习平台」（暂定名，仓库名沿用项目名「工作台」），要改名只动 `brand.name` 这一行。

日程块的视觉只编码「这块能不能动」：课程是实心深绿底白字，来自教务、不可改；自己添加或 AI 已确认的是灰底，可改可删；待确认的是白底虚线，还没生效。类型差异只用块左侧 3px 色条暗示（学习时段靛蓝 / 个人日程琥珀 / 考试赭红），整块不再上色。学生最先要分清的是哪些不能动，不是有哪些类型。

学习偏好是 Planner 的输入，不是一张要学生手画的日历。时段、周末策略、单次时长、每日上限、截止余量共同推导出可用时间池；偏好管「尽量」，例外（实习、家教）管「一定不行」。页面上有句「我这样理解你」把偏好翻译成人话，既是确认点，也是给开发看的数据结构；改动会立刻算出对已确认学习时段的影响，不会悄悄让旧安排落空。

个人中心的学籍字段（姓名、学号、学院、专业、年级）只读，由教务同步，不开放修改；能改的只有头像和昵称，昵称只用于称呼，不替代真名。登录、改密码、找回密码、注销都不在本平台，账号归学校统一身份认证。

`mock.js` 的字段名与 `backend/src/models/index.ts` 保持一致，接接口时不需要二次映射。演示态用 sessionStorage 持久化：任务走 `Store`、日程走 `EventStore`、消息走 `NotifyStore`、管理端数据走 `AdminStore`，同标签页内跨页面共享，关掉标签页复位。改日程必须通过 `commit()` 写回，直接改 `MOCK` 原数组不会触发界面更新。

学期演示口径是 2026–2027 学年第一学期第 12 周（11/16–11/22），「今天」为 11/18 周三。页面里所有统计数字由 mock 实时计算，没有写死。周末保留：课表默认显示周末列，可用时间可含周末，规划器也允许把学习时段排到周末。

AI 规划页的文本是唯一输入入口，按钮和抽屉只负责把结构化选择翻译成一句话塞进输入框，统一走同一个 `send()`；排学习时段前会先扣掉该任务已排过的时长，避免同一项被排两遍。系统管理里发布的公告会直接写入消息中心的「系统公告」来源，顶栏未读角标同步变化，可以去消息页验证。

## 状态说明

这是高保真交互演示：mock 数据、状态变化、弹窗 / 抽屉 / Toast 都能操作，但数据不落库，刷新或关闭标签页后演示态复位。具体到每个接口的改造方案，见《高校智能学习工作台开发交接文档》。
